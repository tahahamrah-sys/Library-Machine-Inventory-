# Library-Machine-Inventory-

Description:
This program is a simple Book Inventory System written in C++. It loads book data from a CSV file and allows basic operations such as viewing, sorting, filtering, searching, and selling books. Each book includes details like title, author, price, year, pages, genre, summary, and number of copies.

Features:

Load books from a CSV file
Display book information (full and compact formats)
Sort books alphabetically by title
Filter books by price, genre, or author and page count
Search books by title (keyword match)
Sell books and update available copies
Save sales records to a file (`sales.txt`)

How to Use:

Provide a CSV file containing book data (default is `books.csv`)
Run the program to automatically perform different operations (printing, filtering, selling, etc.)
